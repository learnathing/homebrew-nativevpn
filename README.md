# NativeVPN Homebrew tap

UniVPN／SecoClient 相容的 legacy SSL VPN 客戶端。正式版與支援範圍見[使用說明](https://github.com/learnathing/nativevpn#readme)。

```sh
brew tap learnathing/nativevpn
brew install --cask learnathing/nativevpn/nativevpn
```

Disconnect and quit before upgrading or uninstalling. No Apple notarization.
Saved scenes, Keychain passwords and gateway trust are retained on uninstall.

Details: https://github.com/learnathing/nativevpn
